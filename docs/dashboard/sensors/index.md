# Sensors in Grillo Cloud

The **Sensors** page shows every Grillo Pulse and Grillo One in the active project, sorted by status with problems first. The heading counts how many sensors are reporting.

Choose a view at the top of the page:

- **Tiles**: one card per sensor with its station code, status, and last 24 hours
- [**Table**](/dashboard/sensors/table-view): one row per sensor, with signal, latency, and firmware
- [**Map**](/dashboard/sensors/map-view): sensors by location

Use **Search sensors…** to find a sensor by station code, and the status buttons to show only **Online**, **Degraded**, **Offline**, or **Disabled** sensors. Each button shows how many sensors it matches. The page updates itself every minute.

Select any sensor to open its [details](/dashboard/sensors/sensor-details).

See [Verify Sensor Status](/dashboard/sensors/sensor-status) for what each status means.

## Changing a sensor

Claiming, editing, and unclaiming a sensor, changing its [recording mode or threshold](/dashboard/sensors/recording-mode), and [updating its firmware](/dashboard/sensors/firmware-updates) are handled by Grillo Support for now. [Contact Grillo Support](/support/contact) with the Device ID and what you need.
