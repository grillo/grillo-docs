# Sensor Table

Open **Sensors** and choose **Table** to see every sensor in the project.

![Sensor table in Grillo Cloud](/img/screenshots/05-sensors.png)

## Columns

| Column | Meaning |
|---|---|
| Status | **online** if the sensor reported in the last 2.5 minutes, otherwise **offline** |
| Station | FDSN station code |
| Device ID | 12-character hardware identifier |
| Type | Grillo Pulse or Grillo One |
| Location | Saved location name |
| Firmware | Firmware version the sensor last reported |
| Last Seen | Time of the most recent health report |

Use the search box to filter by station code or Device ID. Select a column heading to sort. Use the refresh button to fetch current data.

Select a row to open [sensor details](/dashboard/sensors/sensor-details).
