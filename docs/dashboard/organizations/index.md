# Projects and Settings

A project holds one team's sensors, events, and members. Everything you see in Grillo Cloud belongs to your project.

Grillo creates projects for you. To get a new project, [contact Grillo Support](/support/contact).

If you belong to more than one project, switch between them with the project menu at the right of the menu bar.

## Settings

Open **Settings** in the menu bar. The sections are listed on the left in two groups.

**You**

| Section | Shows |
|---|---|
| **Profile** | Your name and email, and the projects you belong to |
| **Notifications** | Emails sent to you. Earthquake alerts are set up on the **Alerts** page |

**Project**

| Section | Shows |
|---|---|
| **General** | The project name and logo |
| **Members** | Who belongs to the project and their roles, and pending invitations. Hidden from viewers. See [Add Colleagues](/dashboard/organizations/managing-members) |
| **Recording & triggers** | Whether sensors record **Continuous** or **Triggered**, the project's **Trigger defaults**, and **Trigger emails**. See [Recording Mode and Thresholds](/dashboard/sensors/recording-mode) and [Trigger Alerts](/dashboard/alerts) |
| **Data** | The [real-time data export](/dashboard/data/realtime-export) to your ringserver, the [seismic data server](/dashboard/data/data-server) your sensors send to, and whether sensor locations are masked |
| **API keys** | Read-only keys for the [Data API](/dashboard/data/api) |
| **Billing** | The plan, billing method, and contract. Owners only. See [Billing](/dashboard/billing) |

The **Project** group is marked **ADMIN** because project owners and admins manage these settings. Grillo staff also see a **Platform admin** group; customers do not.

### Changing settings

Owners and admins change the project's **General**, **Members**, **Recording & triggers**, and **Data** settings on this page. Changes save when you select **Save** in each section.

## Roles

Each person in a project has a role.

| | Viewer | Member | Admin | Owner |
|---|:-:|:-:|:-:|:-:|
| See the Live map, Sensors, Events, Archive, and Alerts | ✓ | ✓ | ✓ | ✓ |
| Change your own profile and language, switch project, log out | ✓ | ✓ | ✓ | ✓ |
| See who belongs to the project in **Settings → Members** | | ✓ | ✓ | ✓ |
| Invite, remove, or change the role of members | | | ✓ | ✓ |
| Add sensors and change sensor settings | | | ✓ | ✓ |
| Change project settings | | | ✓ | ✓ |
| See [Billing](/dashboard/billing) | | | | ✓ |

Owners and admins change people's roles in **Settings → Members**. See [Add Colleagues](/dashboard/organizations/managing-members). For what this means day to day, see [What You Can Do as a Viewer or Member](/dashboard/account/viewer-and-member).

## Leave a project

Go to [cloud.grillo.io/account](https://cloud.grillo.io/account). Your projects are listed there, each with a **Leave** button. Leaving removes your access to that project's sensors.
