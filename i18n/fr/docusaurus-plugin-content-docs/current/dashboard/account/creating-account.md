# Créer un compte Grillo Cloud

Les comptes Grillo Cloud se créent sur invitation. Il vous faut une invitation à un projet avant de pouvoir vous inscrire.

## Recevoir une invitation

Un propriétaire ou un administrateur du projet vous invite depuis **Paramètres → Membres**. Vous recevez un e-mail de Grillo Cloud avec un lien. S’il n’arrive pas, vérifiez le dossier des indésirables (spam), puis demandez à l’administrateur de vérifier l’adresse utilisée.

## S’inscrire

1. Ouvrez le lien de l’e-mail d’invitation, ou allez sur [cloud.grillo.io](https://cloud.grillo.io) et choisissez de vous inscrire.
2. Utilisez **la même adresse e-mail** que celle de l’invitation. L’inscription est refusée avec toute autre adresse.
3. Choisissez l’une des options :
   - **E-mail et mot de passe.** Saisissez votre nom et un mot de passe d’au moins 8 caractères, avec une majuscule, une minuscule, un chiffre et un caractère spécial.
   - **Google** ou **Microsoft.** Connectez-vous avec le compte qui correspond à l’adresse invitée.
4. Si vous avez choisi e-mail et mot de passe, ouvrez le lien de vérification que Grillo Cloud vous envoie par e-mail. Vous pouvez le renvoyer s’il n’arrive pas.

Une fois l’invitation acceptée, Grillo Cloud s’ouvre sur la [carte en direct](/events/live-map) du projet.

## Se connecter

Allez sur [cloud.grillo.io](https://cloud.grillo.io) et connectez-vous avec votre e-mail et votre mot de passe, ou avec Google ou Microsoft.

Mot de passe oublié : saisissez votre e-mail sur la page de connexion et choisissez l’option de mot de passe oublié. Grillo Cloud vous envoie un lien de réinitialisation.

## Choisir la langue et le projet

- **Langue :** à droite de la barre de menu, choisissez **FR** pour le français, **KR** pour le créole haïtien ou **EN** pour l’anglais.
- **Projet :** si vous appartenez à plusieurs projets, choisissez-le dans le menu **Projet**, à côté de la langue.

## « Aucun projet pour le moment »

Ce message signifie que votre compte existe mais n’appartient à aucun projet. Demandez à l’administrateur de votre projet de vous inviter, avec l’adresse e-mail utilisée pour votre inscription.

## Se déconnecter

Cliquez sur le cercle avec vos initiales, à droite de la barre de menu, puis sur **Déconnexion**. Pensez-y sur un ordinateur partagé.
