# Les capteurs dans Grillo Cloud

La page **Capteurs** montre tous les capteurs Grillo Pulse et Grillo One du projet actif, triés par statut, problèmes d’abord. Le titre indique combien de capteurs transmettent.

Choisissez un affichage en haut de la page :

- **Tuiles** : une carte par capteur, avec son code de station, son statut et ses dernières 24 heures
- **Tableau** : une ligne par capteur, avec le signal, la latence et le micrologiciel
- **Carte** : les capteurs selon leur position

**Rechercher des capteurs…** trouve un capteur par son code de station. Les boutons de statut n’affichent que les capteurs **En ligne**, **Dégradé**, **Hors ligne** ou **Désactivé** ; chaque bouton indique combien de capteurs il contient. La page se met à jour toute seule chaque minute.

Cliquez sur un capteur pour ouvrir son détail : connectivité des dernières 24 heures et des 30 derniers jours, signal, alimentation, synchronisation horaire, micrologiciel et position.

Voir [Vérifier l’état des capteurs](/dashboard/sensors/sensor-status) pour la signification de chaque statut.

## Modifier un capteur

Seuls les propriétaires et administrateurs du projet voient **ajouter un capteur** et les réglages d’un capteur. Les lecteurs et les membres voient tous les capteurs et leur détail, sans pouvoir les modifier. Si un capteur doit être modifié, prévenez l’administrateur de votre projet.
