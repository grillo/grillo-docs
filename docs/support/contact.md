# Contact Grillo Support

For product, installation, account, or integration support, email [support@grillo.io](mailto:support@grillo.io) or use the contact options at [grillo.io](https://grillo.io).

## Include with a sensor request

- Device ID
- Product model
- Hardware revision
- Cellular or Ethernet variant
- Firmware version
- Organization and network code
- Station code
- Platform status and last-seen time
- Power supply and connection method
- Carrier and APN for cellular units
- What changed before the problem began
- Photographs of labels, wiring, mounting, antennas, and enclosure where relevant
- Platform screenshots and timestamps

Do not send passwords, API credentials, SIM PINs, or other secrets by email.

## Include with a Platform request

- Account email
- Organization name
- Network code
- Device ID or event ID
- Page and action that failed
- Exact error message
- Browser and approximate time of the problem
- Screenshot with sensitive information removed

## Safety

If a unit appears damaged, wet internally, unusually hot, or electrically unsafe, disconnect it only if that can be done safely and follow the site electrical procedure. Do not continue testing or open a sealed enclosure without authorization.

Grillo products and documentation do not replace instructions from emergency services or official earthquake-warning authorities.
