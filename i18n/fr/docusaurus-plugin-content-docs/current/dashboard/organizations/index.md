# Projets et paramètres

Un projet regroupe les capteurs, les événements et les membres d’une équipe. Tout ce que vous voyez dans Grillo Cloud appartient à votre projet.

Grillo crée les projets. Si vous appartenez à plusieurs projets, passez de l’un à l’autre avec le menu **Projet**, à droite de la barre de menu.

## Paramètres

Ouvrez **Paramètres** dans la barre de menu. Les sections sont listées à gauche, en deux groupes.

**VOUS**

| Section | Contenu |
|---|---|
| **Profil** | Votre nom, votre e-mail et les projets auxquels vous appartenez |
| **Notifications** | Les e-mails qui vous sont envoyés |

**PROJET** (marqué **ADMIN** : réservé aux propriétaires et administrateurs du projet)

| Section | Contenu |
|---|---|
| **Général** | Le nom et le logo du projet |
| **Membres** | Les personnes du projet, leur rôle et les invitations en attente. Masqué pour les lecteurs |
| **Enregistrement et déclencheurs** | Le mode d’enregistrement des capteurs, les seuils de déclenchement et les alertes e-mail |
| **Données** | L’export des données en temps réel, le serveur de données sismiques et le masquage de la position des capteurs |
| **Clés API** | Les clés en lecture seule de l’API de données |
| **Facturation** | Le forfait et le contrat. Propriétaires uniquement |

Les propriétaires et administrateurs modifient ces réglages directement sur cette page, avec **Enregistrer** dans chaque section.

## Rôles {/* #roles */}

Chaque personne d’un projet a un rôle.

| | Lecteur | Membre | Administrateur | Propriétaire |
|---|:-:|:-:|:-:|:-:|
| Voir la carte en direct, les capteurs, les événements, les archives et les alertes | ✓ | ✓ | ✓ | ✓ |
| Modifier son profil et la langue, changer de projet, se déconnecter | ✓ | ✓ | ✓ | ✓ |
| Voir qui fait partie du projet dans **Paramètres → Membres** | | ✓ | ✓ | ✓ |
| Inviter ou retirer des membres, changer leur rôle | | | ✓ | ✓ |
| Ajouter des capteurs et modifier leurs réglages | | | ✓ | ✓ |
| Modifier les paramètres du projet | | | ✓ | ✓ |
| Voir la facturation | | | | ✓ |

Pour changer le rôle de quelqu’un, demandez à un administrateur du projet. Voir aussi [Ce que vous pouvez faire en tant que lecteur ou membre](/dashboard/account/viewer-and-member).

## Quitter un projet

Allez sur [cloud.grillo.io/account](https://cloud.grillo.io/account). Vos projets y sont listés, chacun avec un bouton pour le quitter. Quitter un projet supprime votre accès à ses capteurs.
