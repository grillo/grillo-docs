# Install Grillo Pulse

Grillo Pulse combines a sensitive vertical geophone with a low-noise triaxial MEMS accelerometer. It is available with cellular or Ethernet connectivity for different deployment environments.

:::warning Use the supplied accessories
Power the sensor only with the supplied adapter through its barrel jack. Do not open the enclosure or connect service cables unless instructed by Grillo Support.
:::

For a new sensor, begin with the [Pulse Quick Start](/hardware/grillo-pulse/quick-start).

## Installation sequence

1. [Inspect the shipment and identify the sensor](/hardware/grillo-pulse/whats-in-the-box).
2. Record the Device ID and photograph the external labels.
3. [Claim the sensor in Grillo Platform](/hardware/grillo-pulse/provisioning).
4. Follow the guide for its [cellular or Ethernet connection](/hardware/grillo-pulse/network-setup).
5. Bench-test power, connectivity, and Platform reporting.
6. [Choose and prepare the installation site](/hardware/grillo-pulse/physical-installation).
7. Install the enclosure with the supplied mounting parts and instructions.
8. [Verify status in Platform](/dashboard/sensors/sensor-status) before leaving the site.

## Identify the connection type

Check the order or enclosure label:

- **Pulse Cellular** connects through a mobile network and uses external antennas.
- **Pulse Ethernet** connects to a wired network.

Options vary by order and region. Do not assume that a connection method not listed for your sensor is available.

## Setup is complete when

In Grillo Platform, confirm:

- The Device ID and station code are correct.
- The sensor is Online.
- Last seen is current.
- The displayed connection type matches the installation.
- The saved coordinates and location are correct.
