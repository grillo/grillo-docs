# Sensors in Grillo Platform

The Sensors area lists devices accessible to the active organization and filters them using the selected network.

From this page you can:

- Claim a pre-registered sensor
- Search and sort the sensor table
- Switch between table and map views
- Open device details
- Edit station and location metadata
- Select a target firmware version when supported
- Unclaim a sensor

Start with [Claim a Sensor](/dashboard/sensors/adding-sensor), then [verify its status](/dashboard/sensors/sensor-status).
